
# Acerba Etas

**Acerba Etas** is a Digital Humanities project dedicated to the transcription, study, and digital edition of three medieval manuscripts of *L'Acerba*, the unfinished didactic poem by Cecco d'Ascoli (Francesco Stabili, c. 1269–1327).

## The Project

The project aims to make the manuscript tradition of *L'Acerba* more accessible through digital transcription, textual analysis, and scholarly research.

## Project Website

https://acerbaetas.github.io/

The website is currently under development.

## Status

The project is in its initial development phase. Transcription and editorial work are ongoing.
